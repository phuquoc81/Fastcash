## Usage

### Opening the Application
Simply open `index.html` in a modern web browser. No installation or dependencies required.

### Using the Puzzle Solver

1. **Enter your problem** in the text area
2. **Click "Solve with Phu AI"** or press Ctrl+Enter
3. **View the solution** displayed with quantum confidence metrics

#### Example Queries
```
What is 25 + 17?
Fibonacci sequence for n=10
Is 17 a prime number?
Calculate 5 factorial
Predict the future of quantum computing
```

### Adjusting Settings

#### Optimization Level
- Use the slider to adjust from 1 to 81
- Higher levels provide more thorough analysis
- Default: 81 (maximum optimization)

#### Quantum Boost
- Toggle on/off for enhanced quantum processing
- Recommended: Enabled

#### Phubers Protocol
- **Standard**: Basic processing mode
- **Advanced**: Enhanced capabilities
- **Quantum**: Maximum performance (recommended)
